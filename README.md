# tcm-app
Provide herb recommandation depends on the patient's input. (NER-Symptoms-Herbs-Matcher)

## Dataset Attribution
The training dataset used in this app is a modified version of the [TCM_NER_datasets](https://github.com/cshan-github/TCM_NER_datasets) created by cshan-github. Pinyin features were programmatically added to each token to assist with model training.
